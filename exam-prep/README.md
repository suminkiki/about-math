# 시험 대비

중등 자료는 기존 `grade-N/` 경로를 사용합니다. 고등 자료는 [고등 내신](high-school/README.md), 수능 자료는 [수능·모의고사](csat/README.md)로 구분합니다.

경로: `grade-N/semester-N/midterm/` 또는 `grade-N/semester-N/final/`.

각 폴더에 연도와 세트명을 포함한 Markdown 파일을 추가합니다. `templates/exam-plan.md`를 복사해 범위·학습 일정·문항 구성·채점 기준을 작성합니다. 공통 개념을 복제하기보다 `middle-school`의 해당 단원으로 연결합니다.

학교별 진도 차이가 있으므로 학기 폴더만 보고 범위를 확정하지 않습니다. 학교 기출 원본은 공개 이용 허락이 확인된 경우에만 추가하며, 자체 제작 세트에는 실제 기출이라고 표기하지 않습니다.
