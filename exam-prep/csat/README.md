# 수능·모의고사 대비

수능 **학년도**별로 관리합니다. 예를 들어 `2028`은 2028학년도 시험 자료를 뜻합니다. 실제 시행 연도와 구분해 기록합니다.

| 폴더 | 용도 |
| --- | --- |
| `2027/` | 2027학년도 자료 |
| `2028/` | 2028학년도 자료 |

각 학년도 아래 `topic-practice/`는 주제별 연습, `mock-analysis/`는 모의고사 분석, `final-review/`는 마무리 복습 자료입니다. 이후 학년도도 같은 구조로 추가합니다.

## 범위 구분

- 2027학년도: 수학Ⅰ·수학Ⅱ 공통과 확률과 통계·미적분·기하 중 선택 과목을 구분합니다.
- 2028학년도: 대수·미적분Ⅰ·확률과 통계의 통합형 체제로 분류합니다. 미적분Ⅱ·기하는 고등 내신·심화 학습 자료로 관리합니다.

[교육부 공식 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=340&boardSeq=97621&lev=0&m=020501&opType=N&page=64&s=moe)를 참고하되, 각 학년도 최신 시행계획으로 최종 범위를 확인합니다.

[모의고사 분석 템플릿](../../templates/mock-analysis.md)을 사용합니다. 원문을 재배포하지 않고 공개된 원출처 링크와 자체 작성 분석을 우선 기록합니다. 학생 개별 성적이나 실명은 공개 저장소에 넣지 않습니다.
