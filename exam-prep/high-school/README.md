# 고등 내신 대비

경로: `grade-N/semester-N/midterm/` 또는 `grade-N/semester-N/final/`.

파일명은 `2027-common-math-1-set-01.md`처럼 연도·과목·세트를 포함합니다. [시험 대비 템플릿](../../templates/exam-plan.md)을 복사하고 교육과정, 학교·교과서, 범위, 제외 범위, 확인일을 작성합니다.

동일 학년의 시험이라도 이수 과목이 다를 수 있으므로 과목을 반드시 명시합니다. 문항별로 단원 코드·난이도·배점·서술형 여부를 기록하고, 해설과 채점 기준을 함께 준비합니다.

개념 자료는 `high-school`의 단원에 두고 상대 링크로 연결합니다. 학교 시험지 전체 스캔이나 상용 교재 원본은 공개 이용 허락을 확인하기 전에는 추가하지 않습니다.
