# 고등 수학 자료

고등 자료는 **교육과정 → 과목 → 단원**으로 구분합니다. 같은 과목명이라도 교육과정이 다르면 자료를 별도로 검토합니다. 과목을 학년에 고정하지 않고 학교별 이수 학년·학기를 자료에 기록합니다.

## 단원 안에 쌓을 자료

- 핵심 개념·정의·정리와 성립 조건
- 기본 / 적용 / 도전 수준의 유형별 문제
- 서술형 풀이와 부분점 채점 기준
- 그래프·도형을 이용한 대안 풀이와 오개념
- 관련 강의·숏폼 링크

[이차함수 예시](curriculum-2022/common-math-1/units/quadratic-functions/README.md)를 참고하세요.

## 내신과 수능 연결

- 내신 세트는 [고등 내신 대비](../exam-prep/high-school/README.md)에 둡니다.
- 모의고사 분석·수능 실전 세트는 [수능 대비](../exam-prep/csat/README.md)에 둡니다.
- 강의는 `lectures/lessons/단원코드/README.md`로 연결합니다.
